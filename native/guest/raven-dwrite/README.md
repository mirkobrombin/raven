# DirectWrite component

`dwrite.c` is Raven code, built by `scripts/provision-controls.py` into `raven-dwrite.dll` for 64-bit programs. It
supplies `DWriteCreateFactory` and the objects behind it: the factory, the system font collection and its families and fonts, font
files and faces, rendering parameters, glyph run analysis, GDI interop and font fallback.

Fonts are listed, opened, measured and rasterized by the host through `ravenhost.dll` (FreeType); this component keeps the COM
objects, the family and face matching and the composition of glyph run textures. The names that Windows programs ask for (Arial,
Segoe UI, Courier New, ...) are families that answer with the fonts of the host.

`dwrite_tables.h` is generated by `scripts/generate-dwrite-tables.py`: every interface starts from stubs that name the method they
stand for. `RAVEN_TRACE_DWRITE=1` prints a line for each call that reaches a stub.
